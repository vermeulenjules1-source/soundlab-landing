# Sound Lab — Landing page

Contexte partagé pour tout Claude qui travaille sur ce dépôt. À lire avant toute modification.

## Projet
Landing page de Sound Lab, école de DJing professionnelle (fictive, projet étudiant). Site statique HTML/CSS, publié via GitHub Pages. Pas de framework, pas de build.

## Fichiers
- `index.html` : structure et contenu
- `style.css` : tout le style, variables dans `:root`

## Direction artistique (reprise de l'infographie Canva)
- Fond principal : bleu marine `#081d3f` (variantes `#0f1633`, `#09254a`)
- Couleur d'accent : orange `#f8602b`
- Texte : blanc `#ffffff`, bleu marine sur fond orange pour les accroches secondaires
- Cartes à coins très arrondis (`border-radius: 44px`), pleines orange ou contour orange de 4px
- Petit triangle blanc devant les sur-titres
- Titres : Bebas Neue (majuscules condensées) ; texte : Poppins
- Visuels : platines DJ en aplats orange/marine, style flat

## Messages clés
- Slogan : « Mixe ton avenir. »
- Signature : « Apprendre. Créer. Performer. »
- Chiffres : depuis 2012, 1 550 diplômés, 40+ entreprises partenaires, 82 % des diplômés exercent une activité DJ, satisfaction 4,6/5
- Formation : 3 ans, 60 % de pratique, 2 stages obligatoires, alternance possible
- URL : www.soundlabschool.fr

## Règles de travail
- Ne pas introduire de nouvelles couleurs ou polices hors de la DA.
- Mobile first : tester à 375px de large, pas de scroll horizontal.
- Textes en français, ton direct et énergique, tutoiement.
- Une branche par fonctionnalité, pull request avant merge sur `main`.
