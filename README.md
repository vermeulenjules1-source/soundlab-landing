# Sound Lab — Landing page

Landing page statique de l'école de DJing Sound Lab.

## Lancer en local
Ouvrir `index.html` dans un navigateur.

## Publier
Settings > Pages > Source : branche `main`, dossier `/ (root)`.

## Travailler à deux avec Claude
Chacun clone le dépôt et travaille avec son propre Claude. Le fichier `CLAUDE.md` contient la DA et les règles communes : le donner à Claude en début de session pour garder un rendu cohérent.

```bash
git clone <url-du-depot>
git checkout -b ma-fonctionnalite
# ... modifications ...
git add . && git commit -m "Description"
git push origin ma-fonctionnalite
# puis ouvrir une pull request sur GitHub
```
